### Option 1: English (Global Reach — Recommended)

Synthetic cloud audits don't tell the full story about real user performance.

That's why I built and open-sourced **URL Inspector** — a desktop performance engineering suite for deep real-time network telemetry and Core Web Vitals diagnostics.

What it does differently:
⚡ Chrome DevTools Protocol (CDP) socket-level interception
📶 Deterministic traffic shaping (Fast 4G, Slow 4G, 3G, Broadband)
🎯 Pre-audit client bandwidth baseline probe
📊 Real-time Core Web Vitals (LCP, FCP, CLS, TTFB)
🗄️ Embedded SQLite historical database (100% local, zero tracking)
📝 One-click structured .log export

Built with Electron 30, Node.js 20, and pure Vanilla JS/CSS. Zero framework bloat.

### Option 2: Português (Rede Brasil / LATAM)

Auditorias sintéticas em nuvem não mostram a realidade de quem acessa sua aplicação em conexões móveis e instáveis.

Por isso criei e disponibilizei como open source o **URL Inspector** — uma suíte desktop para análise de rede em tempo real e diagnósticos de Core Web Vitals.

Destaques técnicos:
⚡ Interceptação direto no Chromium via Chrome DevTools Protocol (CDP)
📶 Traffic shaping determinístico (4G, 3G e Cabo)
🎯 Teste prévio da banda do testador para isolar gargalos locais
📊 Core Web Vitals em tempo real (LCP, FCP, CLS, TTFB)
🗄️ Histórico salvo em SQLite local (WebAssembly, 100% privado)
📝 Exportação de logs estruturados em .log com um clique

Construído com Electron 30, Node.js 20 e Vanilla JS/CSS. Zero bloat.
