### Option 1: English (Minimalist)

Synthetic cloud audits don't reflect real user network constraints.

I built URL Inspector, an open-source desktop tool for real-time web diagnostics, network traffic shaping, and Core Web Vitals.

- Chrome DevTools Protocol socket-level telemetry
- Deterministic network throttling (LTE, 4G, 3G)
- Pre-audit client bandwidth and latency baseline testing
- Real-time LCP, FCP, CLS, and TTFB evaluation
- Local SQLite run history (zero tracking, 100% offline)

### Option 2: Português (Minimalista)

Auditorias sintéticas em nuvem não mostram a realidade de conexões móveis e instáveis.

Criei o URL Inspector, uma ferramenta desktop open source para diagnóstico de rede em tempo real, traffic shaping e Core Web Vitals.

- Telemetria no nível de socket via Chrome DevTools Protocol
- Emulação determinística de rede (4G, 3G, Cabo)
- Medição prévia da banda do testador
- Cálculo em tempo real de LCP, FCP, CLS e TTFB
- Histórico local em SQLite (sem tracking, 100% privado)
