# Security Policy

## Supported Versions

Security updates and patches are actively maintained on the latest minor release of URL Inspector.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The URL Inspector maintainers take the security of the software and its users seriously.

If you discover a security vulnerability in URL Inspector, please do **NOT** report it in a public GitHub issue.

Instead, please report security issues privately:
1. Open a **Private Vulnerability Advisory** directly on the GitHub repository:  
   [https://github.com/jaccon/url-inspector/security/advisories](https://github.com/jaccon/url-inspector/security/advisories)
2. Or contact the project lead, **André Jaccon**, via GitHub profile:  
   [https://github.com/jaccon](https://github.com/jaccon)

Please include:
- A description of the vulnerability and its potential impact.
- Clear steps or a proof of concept (PoC) demonstrating how to reproduce the issue.
- Your suggested remediation or workaround, if available.

### Disclosure Policy
We will acknowledge receipt of your vulnerability report within 48 hours and work with you to analyze, reproduce, and patch the issue before publicly releasing an advisory and fix.
